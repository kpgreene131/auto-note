# Research

Notes from exploring documentation, libraries, and technologies. This is a knowledge base — not implementation plans.

## Purpose

- Capture learnings from official docs
- Record technology research before decisions
- Provide context for specs and ADRs

## Workflow

1. Research a topic, capture notes here
2. If research leads to a decision → write an ADR
3. If research informs implementation → reference it in the spec
