# Prompt Iteration Log

Tracks the evolution of AI prompts used in the application. Every prompt change should be logged here with rationale.

## Format

Each entry follows this structure:

```
### Prompt: <name> — v<number>

**Status:** active | deprecated | experimental

**Prompt text:**
> The full prompt text, or a reference to its location in code.

**What changed:** Description of what changed from the previous version.

**Why:** Rationale for the change — what problem it solved or what improvement it made.
```
